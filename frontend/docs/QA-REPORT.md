### QA-01 — Приложение не показывает офлайн-страницу при запуске без сети

**Приоритет: высокий.** Затрагивает заявленный офлайн-сценарий PWA.  
**Шаги:** 1. Открыть серверную сборку с интернетом и дождаться активации Service Worker. 2. Отключить сеть. 3. Перезагрузить приложение на «Сегодня» или открыть маршрут `#/offline` и перезагрузить.  
**Ожидание:** открывается сохранённая оболочка с информационной офлайн-страницей.  
**Факт:** HTML загружается из кеша, но неудачный запрос состояния блокирует маршруты. Видно только «Не удалось подключиться к серверу Хабитона». После восстановления сети и ручной перезагрузки интерфейс снова доступен. [Скриншот](qa-offline-failure.png).  
**Рекомендация:** дать публичным маршрутам отрисоваться, при недоступном API показывать офлайн-страницу с кнопкой повтора. Хранение персональных данных для чтения без сети — отдельное решение; для исправления обязательного информационного экрана оно не требуется.

### QA-02 — Клавиатурная ссылка «Перейти к содержимому» уводит с текущего экрана

**Приоритет: средний.** Затрагивает клавиатурную навигацию.  
**Шаги:** 1. Открыть «Сегодня». 2. С помощью Tab перейти к ссылке «Перейти к содержимому». 3. Нажать Enter.  
**Ожидание:** URL не меняется, фокус переходит на основное содержимое.  
**Факт:** URL меняется с `#/today` на `#main`; HashRouter воспринимает это как другой маршрут.  
**Рекомендация:** по нажатию фокусировать элемент `main` без изменения хеша.

## Расхождения с ТЗ

- **Напоминания:** экран сообщает, что напоминания недоступны; в ТЗ указана настройка браузерных уведомлений.
- **Удаление аккаунта:** в проверяемой версии нет пользовательского сценария и серверной операции удаления собственной учётной записи по подтверждённому запросу.
- **Регрессионные тесты:** файл тестов дат удалён в рабочей копии. Команда тестирования завершается зелёным статусом с нулём тестов; перед релизом стоит вернуть проверку в обычный запуск.
