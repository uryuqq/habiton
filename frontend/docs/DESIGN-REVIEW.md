# Основа дизайна и соответствие макетам

Проверка выполнена 22 октября 2026 года. Источники: Figma `xGliEkjg2BsoyUY5G1lGrd`, сохранённый дизайн-атлас и ТЗ проекта.

## Что подтверждено

В файле Figma находятся страницы «десктоп», «планшет», «мобилка» и «Компоненты». На каждом размере предусмотрены 32 сценария в светлой и тёмной темах. Для вёрстки это 32 маршрута или состояния с адаптивным оформлением, а не 192 независимых React-компонента.

Подробный контекст и изображения через Figma получены для главной, регистрации, первого запуска, ошибки ИИ, сегодняшнего дня, пустого дня, дня без плана, деталей и создания привычки, прогресса, календаря, установки и обзора админки. После этого сработал лимит тарифа Figma MCP. Остальные страницы основаны на сохранённом дизайн-атласе и проверенной структуре файла. Полное попиксельное совпадение всех актуальных макетов не подтверждено.

SVG главной, растения и значков загружены локально. Логотип взят из подготовленного UI kit. Временные URL Figma не используются при запуске приложения.

## Сохранённые решения

- Палитра UI kit с отдельными значениями светлой и тёмной тем.
- Arial для интерфейса, Georgia для акцентных заголовков.
- Кнопки высотой от 48 px, область чекбокса 44 × 44 px.
- Нижняя навигация на телефоне и боковая на широком экране.
- Карточки привычек, отдельные состояния выполнения и архив.
- Просмотр и изменение плана до добавления привычек.
- Карточки записей админки на телефоне, таблицы с ровными границами на широком экране.
- Логотип на главной, без добавления лишних брендовых шапок на все страницы.

## Осознанные изменения для работающего фронтенда

- Текущие даты вместо статической даты макета.
- Расчёт статистики по локальным отметкам вместо статических чисел.
- Явная подпись деморежима, поскольку сервер ещё не подключён.
- Страница всех экранов для проверки преподавателем.
- Честные сообщения о неподключённых ИИ и уведомлениях.
- Дополнительная системная тема и управление обновлением PWA.

## Карта сценариев

Полный список находится в `src/routing/paths.js` и доступен в интерфейсе по `#/screens`. Экран ошибки ИИ, пустой день и день без плана доступны отдельно, чтобы проверить состояния без удаления своих данных. Редактор создания и изменения привычки использует один компонент. Редактор шаблона поддерживает создание и изменение.

Фронтенд проверяется отдельно от реального iPhone. Установка, системные отступы и поведение конкретной версии Safari требуют проверки на устройстве после публикации.
