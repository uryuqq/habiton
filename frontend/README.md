# Хабитон

Клиентская часть PWA на React, React Router и CSS Modules. Laravel и MySQL пока не подключены. Поведение интерфейса проверяется на локальных демонстрационных данных.

## Запуск

Требуется Node.js 22.12+ или совместимая более новая версия.

```bash
cd frontend
npm ci
npm run dev
```

Production-проверка с офлайн-режимом:

```bash
npm run build
npm run preview
```

## GitHub Pages

Репозиторий: `habiton`. Публикация через `gh-pages` по учебной инструкции:

```bash
cd frontend
npm run deploy
```

Команда сначала собирает клиент с базовым адресом `/habiton/`, затем отправляет `dist` в ветку `gh-pages`. Для этого нужны созданный репозиторий, адрес `origin` и авторизация GitHub. В **Settings → Pages** выберите **Deploy from a branch → gh-pages → / (root)**.

Будущий адрес: `https://ИМЯ_АККАУНТА.github.io/habiton/`. Это шаблон, не подтверждение публикации.

Исходники остаются в основной ветке. Позже рядом с `frontend/` можно добавить `backend/`. GitHub Pages выполняет только статический фронтенд; Laravel потребуется отдельный PHP-хостинг.

## Возможности

- 32 сценария макетов: публичная часть, привычки, помощник, план, статистика, профиль, админка и системные состояния.
- Адаптивность от 360 px, светлая и тёмная темы.
- Создание, изменение, архивирование и восстановление привычек.
- Отметки по датам, календарь, статистика и история расписаний.
- Демодиалог и редактирование плана до сохранения.
- Демопользователи, шаблоны, мониторинг и журнал админки.
- Иконки PWA и Apple, манифест, предварительный кеш production-сборки.

## Ограничения

Все данные находятся в `localStorage` текущего браузера. Пароли не сохраняются и не отправляются. Нет настоящей регистрации, внешнего ИИ, фоновой доставки уведомлений или синхронизации между устройствами. Демороль не заменяет проверку прав на сервере.

Без сети доступен просмотр сохранённой оболочки и демоданных. Для новых отметок требуется сеть; очереди последующей синхронизации нет.
