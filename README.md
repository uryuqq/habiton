# Хабитон

PWA для формирования и отслеживания полезных привычек.

[Открыть приложение](https://uryuqq.github.io/habiton/)

- `frontend/` — React, React Router, CSS Modules и демонстрационная логика.
- Серверная часть Laravel и MySQL будет добавлена отдельным этапом.

Подробные команды запуска, публикации и объяснение устройства проекта находятся в [frontend/README.md](frontend/README.md).
