# Хабитон на Railway

Приложение: один сервис React + PHP 8.4/Apache, база: отдельный MySQL. Корень сайта — /var/www/html, PHP и настройки находятся вне публичной папки. Сборка не включает локальный config.php, ключи, тесты и учебные документы.

## 1. Отправить исходники на GitHub

В корне репозитория должны быть Dockerfile, .dockerignore, railway.json, deploy, frontend и backend. Ключ Groq в GitHub не добавлять. Локальный backend/config.php исключён из Git и Docker.

## 2. Создать проект

В Railway: New Project → Deploy from GitHub repo → uryuqq/habiton. При необходимости разрешите Railway доступ только к этому репозиторию.

В этом же проекте: New → Database → MySQL. Имя сервиса базы оставьте MySQL — ниже ссылки переменных используют именно его. Дождитесь запуска базы.

## 3. Настроить сервис приложения

В сервисе приложения, Variables → Raw Editor, добавьте:

```env
PORT=8080
APP_HTTPS=true
DB_HOST=${{MySQL.MYSQLHOST}}
DB_PORT=${{MySQL.MYSQLPORT}}
DB_NAME=${{MySQL.MYSQLDATABASE}}
DB_USER=${{MySQL.MYSQLUSER}}
DB_PASSWORD=${{MySQL.MYSQLPASSWORD}}
QWEN_URL=https://api.groq.com/openai/v1/chat/completions
QWEN_MODEL=qwen/qwen3.8-27b
QWEN_KEY=ВСТАВЬ_КЛЮЧ_GROQ
```

Если сервис базы назван иначе, замените MySQL на его имя во всех ссылках. Ключ вставляйте только в Variables. При изменении настроек нажмите Deploy.

Settings → Source: Root Directory должен быть пустым (корень репозитория), не frontend и не backend. Dockerfile обнаруживается в корне.

railway.json задаёт подготовку таблиц командой php /var/www/backend/migrate.php перед запуском. Вручную импортировать schema.sql не нужно. При повторном запуске существующие таблицы не удаляются.

## 4. Получить HTTPS-адрес

Settings → Networking → Generate Domain. Target port: 8080. Откройте полученный HTTPS-адрес.

Проверки:
- /api/ возвращает {"data":null,"id":null} для гостя.
- /#/signup — регистрация.
- /#/coach?new=1 — тестовая цель «Хочу читать по 10 минут утром».
- Если Groq снова выдаёт 403, размещение само по себе проблему доступа не устранило. Не переносите рабочие данные до успешного запроса.

Данные из MAMP и Джино не переносятся автоматически: это новая база.

## 5. Администратор

После регистрации в таблице users через SQL-консоль базы обновите только свою запись:

```sql
UPDATE users SET role='admin', name='Алексей'
WHERE email='ВАША_ПОЧТА';
```

Обновите страницу профиля — появится админка.

## 6. Показ с iPhone

Откройте HTTPS-ссылку в Safari → Поделиться → На экран Домой. Сначала откройте приложение с интернетом, чтобы Service Worker подготовил кеш. Без сети после перезапуска открывается информационный экран; личные данные повторно загружаются с сервера после подключения.

## Бюджет и ограничения

В панели Billing проверьте фактически выданный trial-бюджет. Не включайте платную подписку для этого прогона. Проверяйте расход ежедневно: PHP и постоянно работающая MySQL расходуют кредит, недели работы заранее гарантировать нельзя.

PHP-сессии хранятся в контейнере и сбрасываются при его пересоздании: потребуется повторный вход, привычки в MySQL сохранятся. Используется один экземпляр приложения.
